# Frontend Fundamentals 모의고사

## UX 개선

1. api 에러 발생 시 재시도 ui를 통해 유저가 재시도를 할 수 있게 처리하였으며, 발생하는 에러 코드를 화면에 표시해 CS 인입 시 보다 빠르게 원인을 파악할 수 있게 처리하였습니다.
2. 목표 금액, 월 납입액에서는 숫자만 입력 가능하게 처리했습니다.

## 서브 태스크 및 체크 리스트

### 적금 상품 목록 연동하기

- [ ] `GET /api/savings-products`를 통해 데이터를 불러와서 화면에 그린다.
- [ ] 원단위를 표시할 때 쉼표(,)로 끊어서 출력한다.
- [ ] api fetch에 대해서 적절한 loading 처리를 한다.
- [ ] api가 실패 시 에러 핸들링을 수행한다.

### 저축 목표 입력 기능 만들기

- [ ] 목표 금액, 월 납입액, 저축 기간을 입력할 수 있다.
- [ ] 월 납입액의 조건을 만족한다. (`product.minMonthlyAmount` (최소 월 납입액)보다 크고, `product.maxMonthlyAmount` (최대 월 납입액)보다 작아야 함)
- [ ] 저축 기간의 조건을 만족한다. (`product.availableTerms` (저축 기간)와 동일해야 함)
- [ ] 금액에는 숫자만 입력 가능하다.
- [ ] 조건에 맞는 적금 상품을 필터링하여 표시한다.

### 적금 상품 목록에서 선택 기능 만들기

- [ ] 적금 리스트는 하나만 선택 가능하다.
- [ ] 선택된 적금 상품은 초록색 체크 박스로 표시한다.

### 계산 결과 탭 만들기

#### 계산 결과

- [ ] 적금 상품이 선택되지 않으면, "상품을 선택해주세요"를 출력한다.
- [ ] 예상 수익 금액을 표시한다. (`최종 금액 = 월 납입액 * 저축 기간 * (1 + 연이자율 * 0.5)`)
- [ ] 목표 금액과의 차이를 표시한다. (`목표 금액과의 차이 = 목표 금액 - 예상 수익 금액`)
- [ ] 추천 월 납입 금액을 표시한다. (`월 납입액 = 목표 금액 ÷ (저축 기간 * (1 + 연이자율 * 0.5))`, 1,000원 단위로 반올림)

#### 추천 상품 목록

- [ ] 사용자가 입력한 조건에 맞는 상품 중 이자율이 가장 높은 상품 2개를 출력한다.
- [ ] 만약 사용자가 선택한 상품이 있다면 적금 상품 목록과 마찬가지로 선택 아이콘을 표기한다.
